# Betwatch Racing API

> Australian, New Zealand, and international racing data and live odds over HTTP and Server-Sent Events.

Base URL: https://api-beta.betwatch.com/v2. Data requests require an X-API-Key header;
these documentation files and the OpenAPI contract are public. Use only the
versioned public API, not the web app's private endpoints. Snapshot first,
then follow the stream instead of polling. Follow opaque pagination cursors
without parsing or constructing them. Read authentication, limits, errors and
streaming before implementing a client.
